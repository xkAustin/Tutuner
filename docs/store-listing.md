## 中文

### 名称

Tutuner

### 副标题

离线吉他调音器与高精度节拍器

### 简短描述

实时识别吉他音高，支持 24 平均律、特殊调弦、自动识弦与稳定节拍；完全离线，无账号、无广告。

### 完整描述

Tutuner 将实时吉他调音器和高精度节拍器放在一个简洁的跨平台应用中。

调音器使用设备麦克风在本机分析音高，支持标准调弦、14 套常见特殊调弦、自定义调弦、自动识弦与手动锁弦。24 平均律模式以 50 cents 为一个音级，并可调整 A4 参考频率、输入门限、灵敏度和准确范围。

节拍器支持 30–300 BPM、Tap Tempo、常见与自定义拍号、四种细分、逐拍重音/普通/静音、三套离线音效，以及独立的声音、视觉和移动端振动开关。暂停会保留拍位，停止会复位到第一拍。

Tutuner 不要求账号，不显示广告，不包含遥测或跟踪 SDK。麦克风采样只在内存中实时处理，不录制、不上传。所有设置、收藏和自定义调弦都保存在设备本地。

## English

### Name

Tutuner

### Subtitle

Offline guitar tuner and metronome

### Short description

Real-time guitar tuning, 24-TET, custom tunings, automatic string detection, and a precise offline metronome—with no ads or account.

### Full description

Tutuner combines a real-time guitar tuner and a precise metronome in one focused cross-platform app.

The tuner analyzes pitch locally from the device microphone. It includes standard tuning, 14 common alternate tunings, custom tunings, automatic string detection, and manual string lock. Its 24-TET mode uses 50-cent steps, while reference pitch, noise gate, sensitivity, and in-tune range are adjustable.

The metronome supports 30–300 BPM, Tap Tempo, preset and custom time signatures, four subdivisions, per-beat accent/normal/mute controls, three offline sound sets, and independent sound, visual, and mobile haptic options. Pause preserves the current position; Stop resets the next start to beat one.

Tutuner requires no account, contains no ads, and includes no telemetry or tracking SDK. Microphone samples are processed only in memory and are never recorded or uploaded. Settings, favorites, and custom tunings remain on the device.
